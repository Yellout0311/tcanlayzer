# BYSO - Before You Seal On

긴 이용약관을 AI가 자동으로 분석하고 핵심 내용만 요약해주는 
크롬 익스텐션 + 웹 서비스
---

## 주요 기능

-  **약관 자동 크롤링** - 웹페이지에 약관이 뜨면 크롬 익스텐션이 
  자동으로 감지하고 텍스트를 수집
-  **AI 분석** - 수집된 약관을 LLM이 분석해 핵심 내용과 
  불리한 조항을 요약
-  **분석 기록 관리** - 분석한 약관 내용을 웹페이지에서 
  저장하고 다시 확인할 수 있습니다.
-  **간편한 UI/UX** - 누구나 쉽게 사용할 수 있는 
  직관적인 인터페이스를 제공
